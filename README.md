# Linux Enumeration 101

A beginner-friendly Linux Enumeration lab built on Debian to help learners practice Linux reconnaissance, service enumeration, and web enumeration in a controlled virtual environment.

---

## Overview

Linux Enumeration 101 is a hands-on cybersecurity lab inspired by real-world penetration testing and CTF environments. The lab provides a safe platform for beginners to perform network reconnaissance, identify exposed services, enumerate web directories, and strengthen Linux enumeration fundamentals.

---

## Features

- Beginner-friendly Linux enumeration lab
- Apache web server hosting a custom landing page
- SSH service for remote access
- Network reconnaissance using Nmap
- Web directory enumeration using Gobuster
- Debian-based virtual machine
- Structured learning objectives


## Learning Objectives

- Discover live hosts
- Identify open ports and running services
- Perform web directory enumeration
- Practice Linux reconnaissance techniques
- Understand a basic penetration testing workflow
